1. Tworzenie geometrii#

Geometrie w PyQGIS mozna tworzyc na trzy sposoby: z listy wspolrzednych, z formatu WKT lub z formatu WKB. W tym cwiczeniu skupiamy sie na pierwszych dwoch.

Każdą geometrię dodaj do tymczasowej warstwy w QGIS tak żeby była widoczna na mapie. Poniżej fragment kodu przykładowego do dodania punktu do warstwy tymczasowej. Modyfikuj go odpowiednio.

from qgis.core import QgsVectorLayer, QgsFeature, QgsGeometry, QgsPointXY, QgsProject

wl = QgsVectorLayer('Point?crs=EPSG:4326', 'test', 'memory')

f = QgsFeature()
f.setGeometry(QgsGeometry.fromPointXY(QgsPointXY(17.038, 51.108)))
wl.dataProvider().addFeature(f)

QgsProject.instance().addMapLayer(wl)
iface.mapCanvas().refresh()

Zadanie 3.1 — Tworzenie QgsFeature#

Uruchom i przeanalizuj ponizszy kod:

from qgis.core import (
    QgsFeature, QgsGeometry, QgsPointXY,
    QgsFields, QgsField
)
from PyQt5.QtCore import QVariant

# Definicja pol atrybutow
pola = QgsFields()
pola.append(QgsField('name',    QVariant.String))
pola.append(QgsField('pop',     QVariant.Int))
pola.append(QgsField('area_km2', QVariant.Double))

# Tworzenie obiektu
obiekt = QgsFeature(pola)
obiekt.setGeometry(QgsGeometry.fromPointXY(QgsPointXY(17.038, 51.108)))

# Przypisanie atrybutow

4. Tworzenie warstwy tymczasowej#

Warstwa tymczasowa (dostawca 'memory') istnieje tylko w pamieci — znika po zamknieciu QGIS. Uzywamy jej do przechowywania wynikow posrednich lub do demonstracji przed zapisem do pliku.

Zadanie 4.1 — Pierwsza warstwa tymczasowa#

Uruchom ponizszy kod i sprawdz czy warstwa pojawila sie w Panelu warstw:

from qgis.core import QgsVectorLayer, QgsProject

wl = QgsVectorLayer(
    'Point?crs=EPSG:4326&field=name:string&field=pop:integer',
    'moje_miasta',
    'memory'
)

if wl.isValid():
    print('Warstwa utworzona poprawnie.')
    print(f'Nazwa          : {wl.name()}')
    print(f'CRS            : {wl.crs().authid()}')
    print(f'Liczba pol     : {wl.fields().count()}')
    print(f'Liczba obiektow: {wl.featureCount()}')
    print(f'Dostawca       : {wl.dataProvider().name()}')
else:
    print('Blad tworzenia warstwy.')

QgsProject.instance().addMapLayer(wl)

Pytanie 4.1 — Co oznacza parametr 'memory' w konstruktorze QgsVectorLayer? Czym rozni sie warstwa z dostawca 'memory' od warstwy z dostawca 'ogr'?

Zadanie 6.1 — Zapis do GeoPackage#

Zapisz warstwe moje_miasta do pliku GeoPackage:

from qgis.core import QgsVectorFileWriter, QgsProject

wl = QgsProject.instance().mapLayersByName('moje_miasta')[0]
SCIEZKA = 'C:/GIS_kurs/C4/moje_miasta.gpkg'  # zmien na swoja sciezke

opcje = QgsVectorFileWriter.SaveVectorOptions()
opcje.driverName   = 'GPKG'
opcje.fileEncoding = 'UTF-8'

blad, komunikat, sciezka_wyj, _ = QgsVectorFileWriter.writeAsVectorFormatV3(
    wl,
    SCIEZKA,
    QgsProject.instance().transformContext(),
    opcje

if blad == QgsVectorFileWriter.NoError:
    print(f'Zapisano: {sciezka_wyj}')

Zadanie 6.3 — Zapis z reprojekcja#

Zapisz warstwe moje_miasta do pliku GeoPackage z jednoczesna reprojekcja do ukladu EPSG:2180 (PL-1992):

from qgis.core import (
    QgsVectorFileWriter, QgsProject,
    QgsCoordinateReferenceSystem, QgsCoordinateTransform
)

wl = QgsProject.instance().mapLayersByName('moje_miasta')[0]

opcje = QgsVectorFileWriter.SaveVectorOptions()
opcje.driverName   = 'GPKG'
opcje.fileEncoding = 'UTF-8'
opcje.ct = QgsCoordinateTransform(
    wl.crs(),
    QgsCoordinateReferenceSystem('EPSG:2180'),
    QgsProject.instance()
)

blad, _, sciezka_wyj, _ = QgsVectorFileWriter.writeAsVectorFormatV3(
    wl, 'C:/GIS_kurs/C4/moje_miasta_PL1992.gpkg',
    QgsProject.instance().transformContext(), opcje
)

if blad == QgsVectorFileWriter.NoError:
    print('Zapisano w EPSG:2180.')
    # Wczytaj i sprawdz CRS
    from qgis.core import QgsVectorLayer
    sprawdz = QgsVectorLayer(sciezka_wyj, 'sprawdzenie', 'ogr')
    print(f'CRS zapisanego pliku: {sprawdz.crs().authid()}')

Napisz skrypt ktory:

  1. Tworzy warstwe tymczasowa punktowa w EPSG:4326 z polami: nazwa (String), lon (Double), lat (Double), wysokosc_m (Int), kraj (String).

  2. Tworzy obiekt QgsFeature dla kazdego wulkanu i dodaje wszystkie naraz przez dataProvider().addFeatures().

  3. Wyswietla raport w konsoli:

    • liczbe dodanych obiektow,

    • nazwe najwyzszego wulkanu,

    • srednia wysokosc wszystkich wulkanow.

  4. Dodaje warstwe do projektu QGIS.

  5. Zapisuje warstwe do pliku wulkany.gpkg w EPSG:4326 ORAZ do pliku wulkany_geojson.geojson w formacie GeoJSON.

  6. Wyswietla rozmiary obu plikow w bajtach.

Wymagania:

  • caly potok w jednym skrypcie,

  • odpowiednia obsluga bledu zapisu (sprawdz kod bledu),

  • po uruchomieniu punkt dla kazdego wulkanu ma byc widoczny na mapie.

Podsumowanie C4#

W tym cwiczeniu pracowales/pracowałas z:

  • QgsGeometry — tworzenie z wspolrzednych i WKT, odczyt wlasciwosci,
